# Rizzly MVP - Development Plan

## 1. Application Type
- Web Application (Single-Page App experience via Gradio, similar to Streamlit)

## 2. Core Technologies
- **UI:** Gradio
- **Backend/Orchestration:** Python + Langchain
- **AI Model Provider:** Groq API (using `langchain-groq`)

## 3. Input Method
- User copies text from their chat application (e.g., WhatsApp, Tinder) and pastes it into the Rizzly interface.

## 4. User Interface (Gradio)
- **Required Input:** Textbox for "Received Message".
- **Optional Context Inputs:**
    - Textbox for "My Last Message (Optional)".
    - Textbox for "Brief Situation (Optional)" (e.g., "First date follow-up", "Met at party").
- **Action:** Button labeled "Generate Rizz Replies".
- **Output:** Area to display multiple suggested replies generated by the AI.
- **Potential Enhancement:** "Smart Paste" - auto-trigger generation upon pasting into the main input box.

## 5. Backend Logic (Python + Langchain)
- Receive all text inputs from the Gradio interface.
- Utilize a Langchain `PromptTemplate` that dynamically incorporates the received message and any provided optional context fields to construct a detailed and effective prompt for the AI model.
- Use Langchain's `ChatGroq` integration to interact with the selected Groq model (e.g., Llama 3, Mixtral).
- Process the AI's response (list of suggested replies).
- Return the suggestions back to the Gradio interface for display.

## 6. High-Level Architecture Diagram (Mermaid)
```mermaid
graph LR
    A[User Mobile Browser] -- Interacts --> B(Gradio Web Interface);
    B -- Sends Inputs (Received Msg, Context) --> C{Python Backend (app.py)};
    C -- Invokes Langchain Chain (chains.py) --> E[Langchain: PromptTemplate + ChatGroq];
    E -- Sends Formatted Prompt --> D[Groq API];
    D -- Returns Generated Replies --> E;
    E -- Returns Replies --> C;
    C -- Updates UI --> B;
```

## 7. Proposed Project Structure
```
rizzly/
├── app.py           # Main Gradio UI and interaction logic
├── chains.py        # Langchain prompt templates and chains
├── requirements.txt # Dependencies
├── .env             # Store GROQ_API_KEY
└── .gitignore
```

## 8. Dependencies (`requirements.txt`)
- `gradio`
- `langchain`
- `langchain-groq`
- `groq`
- `python-dotenv`

## 9. Initial Deployment / Running
- Run locally using `python app.py`. Requires Python environment and installed dependencies.
- Requires a `.env` file containing `GROQ_API_KEY=your_actual_key`.

## 10. Future Phases / Potential Enhancements
- PWA features (installability, potentially offline elements).
- Screenshot input support (requires OCR or multimodal model).
- User accounts / history saving.
- More sophisticated context handling (conversation memory).
- Tone selection (funny, romantic, witty).
- Browser extension or native mobile app integration (significant effort).
